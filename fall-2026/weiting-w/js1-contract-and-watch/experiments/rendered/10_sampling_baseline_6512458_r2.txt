THE RULE (R-v2). There are four gates. A posting is "relevant" only if all
four pass.

G1_title_block - fails if the posting title contains, as a whole word, any
  token in title_block. Whole word means bounded by a non-letter or by the
  start or end of the string, so "sr" does not match "sre" and "lead" does
  not match "leadership".
G2_discipline - fails if the posting title contains none of the phrases in
  target_title_phrases as a substring.
G3_job_family - let F be the value of the posting's metadata entry whose
  name is "Job Family". Fails if F is missing, empty, or contains none of the
  phrases in target_job_families as a substring.
G4_location - fails if the posting's location name contains none of the
  phrases in locations_ok as a substring, and it is not the case that
  remote_ok is true and the location name contains "remote".

All comparisons are case-insensitive. You may use only the posting fields
printed below; there is no job description available to you.
