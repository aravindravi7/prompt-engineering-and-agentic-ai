# Labeling rule — Job-Search Agent 1 prompt experiment

Written 2026-10-31, before labeling any posting. Persona: Priya Nair (fictional).

A posting is **relevant** only if ALL of these hold:

1. **Role type.** It is a role that builds or uses ML/AI or data systems:
   AI engineer, ML engineer, machine learning engineer, data engineer,
   data scientist, data analyst / data analytics, ML infrastructure/platform,
   or applied AI. Research scientist, sales, operations, product, and
   marketing roles are not relevant.
2. **No clearance.** The posting does not require a security clearance.
3. **Sponsorship possible.** The posting does not say that sponsorship is
   not provided, or that candidates who need sponsorship are not eligible.
4. **Reachable experience.** The posting requires at most 2 years of
   experience (internship/co-op experience counts toward it), and the title
   does not say Senior, Staff, Principal, Lead, Manager, or Director.

Otherwise it is **not relevant**. Each label records which condition failed.
